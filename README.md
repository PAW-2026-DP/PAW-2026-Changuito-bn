# Changuito - Backend

Repositorio reservado para la documentación y las pruebas del backend de Changuito, el sistema de compras que compara precios entre supermercados y permite armar pedidos.

Por el momento este repositorio no contiene código ejecutable. La implementación se agregará en las próximas entregas siguiendo el alcance definido en la propuesta general:

- Usuarios y roles: cliente, supermercado, repartidor y administrador.
- Catálogo, precios, stock e historial de modificaciones.
- Listas de compras.
- Optimización de compra en uno o dos comercios.
- Generación y seguimiento de pedidos.
- Paneles para supermercados, repartidores y administración.

## Carpetas

- `docs/`: decisiones y documentación técnica.
- `tests/`: espacio reservado para las pruebas.

## Estado actual

Base documental inicial. No hay archivos PHP, JavaScript, JSON, SQL ni dependencias configuradas todavía.
