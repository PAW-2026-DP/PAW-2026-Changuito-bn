# Arquitectura pendiente

La arquitectura del backend se definirá antes de comenzar la implementación.

Deberá contemplar:

- Separación entre presentación, reglas de negocio y persistencia.
- Autenticación y autorización por rol.
- Consultas parametrizadas a la base de datos.
- Validación de transiciones del ciclo de vida de los pedidos.
- Registro de cambios de precios y estados.
